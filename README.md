# Heart Disease Prediction using Decision Tree

Machine Learning Lab Task 03, SZABIST-ISB

## Description
This project predicts whether a patient has heart disease using a
Decision Tree Classifier.

## Dataset
Heart Failure Prediction Dataset (fedesoriano)
https://www.kaggle.com/datasets/fedesoriano/heart-failure-prediction

## Files
- Decision_Tree_Heart_Disease.ipynb : complete code with outputs
- heart.csv : dataset

## Steps
1. Data exploration
2. Data preprocessing
3. Train-test split (80:20)
4. Decision Tree model
5. Evaluation (accuracy, precision, recall, F1)
6. Confusion matrix

## Results
Accuracy = 0.7772, Precision = 0.7905, Recall = 0.8137, F1-score = 0.8019
